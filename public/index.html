Ubicaciones de Costa Rica

API JSON gratuita con las provincias, cantones, distritos y códigos postales de Costa Rica. Archivos estáticos, CORS abierto y sin API key.

Endpoints

Todos responden GET con JSON. Los números de cantón y distrito van sin ceros a la izquierda.

RutaDevuelve
/provincias.jsonLas 7 provincias
/provincia/{p}/cantones.jsonCantones de una provincia
/provincia/{p}/canton/{c}/distritos.jsonDistritos de un cantón
/codigo-postal/{PCCDD}.jsonnuevoUn distrito por su código postal, con su cantón y provincia
/distritos.jsonnuevoLista plana de todos los distritos con código postal
/todo.jsonnuevoÁrbol completo con códigos oficiales y áreas en km²
/meta.jsonnuevoFuente, edición y totales

Ejemplos

// Cantones de San José
const cantones = await fetch('/provincia/1/cantones.json').then(r => r.json());
// { "1": "San José", "2": "Escazú", "3": "Desamparados", ... }

// Distrito a partir del código postal
const d = await fetch('/codigo-postal/10305.json').then(r => r.json());
// { "codigo_postal": "10305", "distrito": "San Antonio", "canton": "Desamparados",
//   "provincia": "San José", "codigos": { "provincia": 1, "canton": 3, "distrito": 5 }, ... }

Código postal

El código postal de Costa Rica es el código oficial del distrito: P (provincia, 1 dígito) + CC (cantón, 2 dígitos) + DD (distrito, 2 dígitos). Por ejemplo, San Antonio de Desamparados es 1 03 05 = 10305.

Cuando un distrito pasa a otro cantón, su código viejo se retira y no se reutiliza, así que puede haber saltos en la numeración (por ejemplo, Grecia no tiene distrito 6).

Compatibilidad

Las tres primeras rutas tienen la misma forma que la API de ubicaciones.paginasweb.cr, así que podés cambiar solo la URL base. Las diferencias: los nombres son los oficiales del IGN, con tildes (el cantón 1 de cada provincia se llama por su nombre, no "Central"), y los datos están al día con la edición 2026.
