Endpoints

All endpoints answer GET with JSON. Canton and district numbers have no leading zeros. Names and field names are in Spanish, as published by the IGN.

PathReturns
/provincias.jsonThe 7 provinces
/provincia/{p}/cantones.jsonCantons of a province
/provincia/{p}/canton/{c}/distritos.jsonDistricts of a canton
/codigo-postal/{PCCDD}.jsonnewA district by postal code, with its canton and province
/distritos.jsonnewFlat list of every district with its postal code
/todo.jsonnewFull tree with official codes and areas in km²
/meta.jsonnewSource, edition and totals

/llms.txtUsage guide for AI agents (in Spanish)

Examples

// Cantons of San José
const cantons = await fetch('/provincia/1/cantones.json').then(r => r.json());
// { "1": "San José", "2": "Escazú", "3": "Desamparados", ... }

// District from a postal code
const d = await fetch('/codigo-postal/10305.json').then(r => r.json());
// { "codigo_postal": "10305", "distrito": "San Antonio", "canton": "Desamparados",
//   "provincia": "San José", "codigos": { "provincia": 1, "canton": 3, "distrito": 5 }, ... }

Postal codes

A Costa Rican postal code is the official district code: P (province, 1 digit) + CC (canton, 2 digits) + DD (district, 2 digits). For example, San Antonio in Desamparados is 1 03 05 = 10305.

When a district moves to another canton, its old code is retired and never reused, so numbering can have gaps (for example, Grecia has no district 6).

FAQ

How many provinces, cantons and districts does Costa Rica have?

According to the IGN's 2026 Administrative Territorial Division, Costa Rica has 7 provinces, 84 cantons and 494 districts. The newest cantons are Monteverde and Puerto Jiménez, in Puntarenas. The newest districts are Pijije (Bagaces) and Cabagra (Buenos Aires), created by law in May 2025.

What is the postal code of a district?

It is the district's official 5-digit code. You can look it up in the demo above, or request /codigo-postal/{code}.json to get the district, canton and province for a postal code.

Is the API free? Do I need an API key?

It is free and needs no API key or sign-up. CORS is open, so you can call it directly from a browser, a mobile app or a server.

How often is the data updated?

Whenever the National Geographic Institute publishes a new edition of the Administrative Territorial Division, every two years, or when a law creates a new canton or district. /meta.json shows the current edition.

Why are the names in Spanish?

Province, canton and district names are proper nouns and are kept exactly as the IGN publishes them. JSON field names are also in Spanish (provincia, canton, distrito, codigo_postal) so the API stays compatible with existing integrations.
